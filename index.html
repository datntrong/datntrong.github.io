A little about me

I work on automated software testing and on making large language models useful for it in practice: generating unit tests that actually compile, run and cover the code under test; concolic test-data generation for projects built on framework classes; analysing the impact of code changes; and building multi-agent systems for software engineering tasks. I am part of the Software Quality Assurance Laboratory (RD320) at VNU-UET, where I also did my Bachelor's and Master's degrees. Earlier I worked on speech processing — as an AI engineer at Viettel Telecom — and on medical image analysis.

III /

Research interests

01

Automated unit test generation

Tests are only worth anything if they build, run and exercise the target. I work on pipelines that validate every candidate test end-to-end — pytest for Python, compile-link-execute with gcov/lcov for C++ — and use that signal to train compact models instead of paying for a frontier model per method.

02

Concolic test-data generation

Symbolic execution stalls where a constraint solver alone cannot build the objects a test driver needs — parameters whose types come from a framework such as Qt. Recovering the right constructors, then letting agents drive the search, makes those units testable.

03

LLM agents for software engineering

Multi-agent workflows for repository-scale tasks: change impact analysis, test repair, mutation testing and regression selection — with execution feedback in the loop rather than one-shot prompting.

04

Efficient model adaptation

Knowledge distillation and reinforcement learning with rule-based, verifiable rewards (GRPO), so a model that fits on one GPU keeps most of a much larger teacher's capability at a fraction of the inference cost.

Publications

* equal contribution · † corresponding author

  1. 01

    ConAgent: Agent-based concolic testing to generate test data for Qt projects

    Dat Nguyen Trong, Duc Nguyen Huu, Linh Ngoc Truc Tran, Duc-Anh Nguyen, Pham Ngoc Hung

    Information and Software Technology, vol. 200, art. 108301, 2026

    An agent-based approach to concolic testing that generates test data for C++ projects built on the Qt framework — code that classic concolic tools struggle with, because they cannot instantiate framework classes in a test driver.

    DOI Accepted version Open access

  2. 02

    UnitTestLM for Efficient Unit Test Generation via Distillation and Reinforcement Learning

    Dat Nguyen Trong*, Phuoc Truong Minh*, Chau Nguyen To Trinh, Trung Hau Tran, Duc Anh Nguyen†, Pham Ngoc Hung

    Faculty of Information Technology, VNU University of Engineering and Technology

    A two-stage pipeline — sequence-level distillation on execution-validated targets, then GRPO with rewards for format, build validity, successful execution and focal-method coverage — that lifts a compact student from 36% to 84% statement coverage on Python and from 26% to 73% on C++, at roughly 1/20 of the teacher's inference cost.

    Code Preprint

  3. 03

    Attention-Based Deep Learning Model for Aspect Classification on Vietnamese E-commerce Data

    Ngoc-Tu Nguyen, Trong-Dat Nguyen, Duy-Cat Can, Mai-Vu Tran, Ha Luu Manh, Hoang-Quynh Le

    2021 13th International Conference on Knowledge and Systems Engineering (KSE), pp. 1–6

    Aspect classification for Vietnamese product reviews from Shopee: comments are represented with one-hot, fastText and PhoBERT embeddings, then classified with CNN and multilayer-perceptron models over two product domains.

    DOI
